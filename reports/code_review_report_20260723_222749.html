Problem: Constructing SQL queries by concatenating strings or formatting variables directly allows attackers to inject malicious SQL commands, leading to unauthorized database access, data theft, or database alteration.

Recommended Fix: Use parameterized queries (prepared statements) provided by your database library. Parameterized queries enforce strict separation between SQL code and user data.
